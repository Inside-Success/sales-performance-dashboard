# Coaching terminal outcomes and bounded repair — November 10

## Problem and scope

The new Tyler coaching core returned a valid, independently reviewed exclusion, but both parent adapters required `completed`. Don Beinecke (official) and Jacket Tannenbaum (manual) therefore appeared as processing failures. Separately, Dr. Ollie's first draft had two missing teaching fields. The single repair was told only about the first, fixed it and left the second invalid. The source was held rather than publishing incomplete coaching.

## Changes

- Contract validation reports all detected faults with locations in one pass. The existing single repair sees every fault; independent factual review and safety remain required. No generic filler, relaxed validation, unlimited retry or additional routine model stage.
- A reviewed exclusion has its own source/policy/evidence/digest/paid-receipt validation and maps to the existing official exclusion receipt or manual refusal callback. It cannot create a score, coaching report, Doc or report notification.
- Exact retained first-stage writer/reviewer contract failures can resume into their bounded repair without purchasing the original request again. Their checkpoints remain failed, never approved; reuse has zero new cost. Unknown outcomes, refusal/truncation and repeated repair failures do not gain replay permission.
- Scoped workflow patch preserves all connections, node inventories, credentials and unrelated settings. A new core is used; the previous core stays available for in-flight executions and rollback. Historical reports, prompts, report layout, scoring, compliance, FAQ and adherence remain unchanged.

## Recovery protections and rollback

Before changing live parents, save fresh exact workflow versions and compare them again immediately before publication. Stop on concurrent drift. Recover only exact source identities after terminal execution, current ownership and absence of delivered artifacts are verified. Preserve paid receipts and never reset uncertain requests. Keep the normal source/report duplicate guards and owner-specific settlement.

The private rollout directory `.private-coaching-lab/terminal-recovery-2026-11-10/` retains baseline snapshots, guarded control script and verification evidence. Roll back only changed parent nodes/references against their expected installed state; retain additive receipt support and v3 readers for in-flight work. Do not restore an old whole application over unrelated changes.
