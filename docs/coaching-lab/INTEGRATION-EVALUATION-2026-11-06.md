## Implementation boundary

- Separate `coaching-foundations-v3` contract; old v2 reports are unchanged.
- Pure offline stage adapter binds source, policy, writer/reviewer requests and candidate digest. Canonical hashing tolerates database JSON key reordering.
- Whole-field repairs are restricted to prose. Classification, source identity, evidence, ownership and focus are not repairable prose. Any changed wording invalidates the safety decision.
- Separate official/manual publication envelopes and a matching reader preserve promises, suggestions and positive lessons.
- Real saved outputs replay through that adapter, but safety decisions in this replay are explicitly synthetic. This is **not** a real safety-service or live-workflow test.
- No provider/delivery clients exist in the offline adapter. No accepted dashboard writes, Docs, Slack or production workflow changes occur.
