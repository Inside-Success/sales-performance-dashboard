# Rep-scoring manager view simplification — 2026-08-12

## Purpose

Make the production rep-performance dashboard easier for managers to use without changing scoring, data ingestion, Coaching integration, access control, or stored records.

## Presentation changes

- Removed visible scoring-version, historical-backfill, progress, distribution, and model/prompt diagnostics from the manager workflow.
- Renamed the main page to **Sales rep performance** and shortened the instructions.
- Kept the action-focused summary, rep ranking, filters, scores, recurring findings, trends, call evidence, and transcript links.
- Reworded rep and call details in plain manager language.

## Safety boundary

No n8n workflow, Airtable schema or record, score calculation, rep-priority rule, Coaching report match, authentication rule, or production data source was changed.
