## Behavior

A structured writer identifies observed outcomes, specific strengths, meaningful improvements, actual blockers, and agreed next steps. Two independent factual audits each examine the complete transcript and original analysis. The renderer removes the union of rejected findings, validates source references, credits counterevidence, and labels uncertain effects and optional polish. Hypothetical example dialogue is not published. Actionable advice remains in the existing report fields. There is no forced fault or praise quota.

The instructions incorporate the reviewed Call 2 method and source research: relevant video followed by an initial payment ask is allowed; contract review before payment is permitted; individual payment exceptions are not general policy. A signed agreement, pending payment, received payment, and booked onboarding are distinct outcomes. Feedback votes are sampling signals, not truth labels, and older feedback remains relevant.

Official scoring generation/persistence remains on its original path. Its old coaching output is superseded by the isolated new coaching path. Manual eligibility/refusal remains on the original path; the new checks run only for eligible completed analysis. Existing safety screening, targeted repair, report formatting, and single delivery/callback paths remain.

## Boundaries and limitations

Google Docs, including the shared ISTV context pack, were not edited. No Slack messages, test notifications, duplicate reports, or historical backfill. Compliance prompts/context/categories/risk behavior, Ask Sales, scoring logic, and manager layouts remain outside this release.

The models are probabilistic. Source IDs and dual audits reduce errors but cannot prove every future judgment correct. Isolated additional model latency averaged 156 seconds (95–201); estimated additional model cost averaged $0.70 per call ($0.30–$1.28), excluding existing pipeline calls and retries. Estimates are not billing reconciliation. Provider transport errors remain possible; existing HTTP retry behavior is retained. Invalid or mismatched audit output follows the workflow's error handling rather than publishing unchecked coaching.

Two preview builds failed before build start with resource provisioning errors. A staged production build from the exact Git commit succeeded, followed by the Git main production deployment. Preview infrastructure remains an outstanding platform limitation. No storage integration or build machine settings were changed.
